# Аналитика и панель управления

На сайте свой счётчик: он пишет визиты, клики по контактам и заявки в вашу базу,
а показывает всё это закрытая паролем страница **`/admin`** на самом сайте.
Никаких внешних сервисов и никакой слежки за людьми: IP не сохраняется,
имена и телефоны появляются только из заявок, которые человек отправил сам.


> Дополнительно на сайте стоит **Яндекс.Метрика** (счётчик 114381101) — смотрите её
> в кабинете metrika.yandex.ru. Подробнее — в разделе «Яндекс.Метрика» внизу.

---

## Что нужно один раз настроить

### 1. База данных — Supabase (бесплатно)

1. Зайдите на **supabase.com** → *Start your project* → регистрация по почте или через GitHub.
2. *New project*: имя `baikal-eyes`, придумайте пароль базы (его можно больше нигде не вводить),
   регион — **Central EU (Frankfurt)** или ближайший. Проект создаётся 1–2 минуты.
3. В левом меню **SQL Editor** → *New query* → вставьте целиком файл
   `nextjs/supabase/schema.sql` из этого проекта → **Run**.
   Должно появиться `Success. No rows returned` — таблицы созданы.
4. **Project Settings → API** и скопируйте два значения:
   - `Project URL` → это `SUPABASE_URL`
   - `service_role` (секретный ключ, под надписью *Project API keys*) → это `SUPABASE_SERVICE_KEY`

> ⚠️ `service_role` — ключ с полным доступом. Он живёт только в настройках Vercel,
> в код его вписывать нельзя и в браузер он никогда не попадает.
> Ключ `anon` нам не нужен: таблицы закрыты политикой RLS.

### 2. Переменные окружения в Vercel

Vercel → ваш проект → **Settings → Environment Variables**. Добавьте четыре штуки
для всех окружений (*Production*, *Preview*, *Development*):

| Имя | Значение |
|---|---|
| `SUPABASE_URL` | `https://xxxxx.supabase.co` из Supabase |
| `SUPABASE_SERVICE_KEY` | ключ `service_role` из Supabase |
| `ADMIN_PASSWORD` | пароль для входа в `/admin` — придумайте свой, длинный |
| `ADMIN_SECRET` | любая случайная строка (30+ символов), подписывает куку входа |

Случайную строку можно получить командой `openssl rand -hex 24` или взять любой
длинный набор символов из головы.

После добавления переменных нажмите **Redeploy** на последнем деплое —
без этого новые переменные не подхватятся.

### 3. Готово

Откройте `https://ваш-домен/admin`, введите `ADMIN_PASSWORD` — появится панель.
Вход держится 14 дней, потом пароль спросят снова.

## Что показывает панель

- **Плитки сверху** — просмотры и посетители за сегодня и за выбранный период,
  глубина просмотра, заявки, клики по контактам.
- **График визитов по дням** — просмотры и уникальные посетители; наведение
  показывает точные числа, кнопка «Таблица» — те же данные списком.
- **Страницы, маршруты, источники, города, устройства, браузеры** — топ-списки
  за период.
- **Клики по контактам** — сколько раз нажимали Telegram, телефон, «Забронировать»,
  и с каких маршрутов.
- **Заявки с сайта** — все отправленные формы с контактом, маршрутом и датой.
  Статус меняется прямо в таблице: новая → в работе → оформлена / спам.
- **Журнал визитов** — «кто и когда заходил»: время, страница, город, источник,
  устройство и браузер, с пометкой «впервые» у новых посетителей.

Период переключается кнопками 7 / 30 / 90 дней / год.

## Чего панель показать не может (и почему)

Имена и фамилии посетителей не покажет никакая аналитика — их просто нет в браузере.
Максимум, что доступно честному счётчику: анонимный идентификатор устройства, город
по сети провайдера, устройство и путь по сайту. Человек становится «известным»
только когда сам оставляет заявку — такие записи и лежат в разделе «Заявки».

Город определяется по IP через заголовки Vercel и бывает неточным: у мобильных
операторов это часто город, где стоит их узел связи.

## Как это устроено в коде

```
nextjs/supabase/schema.sql          таблицы visits, events, leads
nextjs/src/lib/db.ts                клиент Supabase на fetch (только сервер)
nextjs/src/lib/ua.ts                разбор устройства/браузера, отсев роботов
nextjs/src/lib/admin-auth.ts        пароль и подписанная кука входа
nextjs/src/components/Analytics.tsx счётчик в браузере (sendBeacon)
nextjs/src/app/api/track/route.ts   приём просмотров и кликов
nextjs/src/app/api/lead/route.ts    приём заявок
nextjs/src/app/api/admin/*          вход, выход, данные для панели
nextjs/src/app/admin/               сама панель
```

Счётчик подключён в `src/app/layout.tsx` и не срабатывает на страницах `/admin`.
Роботы и поисковые краулеры отсеиваются по user-agent, страница `/admin` закрыта
от индексации.

Чтобы отметить кликом любую свою кнопку или ссылку, добавьте ей атрибут:

```html
<a data-track="whatsapp" data-tour="Ольхон за один день" href="...">…</a>
```

Ссылки на `tel:`, `t.me` и Instagram считаются автоматически.

## Если данных нет

- Панель пишет «Не заданы SUPABASE_URL и SUPABASE_SERVICE_KEY» — переменные не
  добавлены или проект не передеплоен после их добавления.
- Панель просит пароль по кругу — не задан `ADMIN_SECRET`, или домен открыт по
  `http://` (кука входа ставится только по https).
- Визитов ноль, хотя заходы есть — проверьте, что в браузере не включён блокировщик,
  и что открываете сайт не в приватном окне (там хранилище очищается).
- Локально (`npm run dev`) города не будет: заголовки геолокации добавляет только Vercel.

## Про закон

Сайт собирает обезличенную статистику и хранит её в Supabase (серверы в ЕС).
Данные из формы заявки — имя и контакт — это персональные данные: по 152-ФЗ
на сайте стоит разместить короткую политику обработки персональных данных и
согласие рядом с кнопкой отправки формы. Скажите — добавлю страницу политики
и чекбокс согласия к формам.

## Яндекс.Метрика

Счётчик **114381101** стоит на всех публичных страницах сайта — первым в `<head>`,
чтобы просмотр засчитывался, даже если человек сразу закрыл вкладку.

- Код лежит в `nextjs/src/lib/metrika.ts`, подключён в `nextjs/src/app/(site)/layout.tsx`.
- Сайт меняет страницы без перезагрузки, поэтому каждый переход отправляется в Метрику
  отдельно (`hit`) — иначе она видела бы только первую страницу визита.
- В панель `/admin` Метрика **не подключена**: Вебвизор записал бы экран с заявками
  клиентов и отправил их в Яндекс.
- Сменить номер счётчика — одна строка `METRIKA_ID` в `metrika.ts`.

Своя панель и Метрика не мешают друг другу: панель — быстрый взгляд и заявки,
Метрика — подробные отчёты, Вебвизор и карта кликов.
