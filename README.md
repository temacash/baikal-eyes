# Baikal Eyes — рабочая папка проекта

## Что где лежит

```
nextjs/           Основной проект сайта: Next.js 14 + TypeScript + Tailwind + Framer Motion.
                  Запуск:  cd nextjs && npm install && npm run dev  →  http://localhost:3000
                  Инструкция и что менять — в nextjs/README.md

prototype/        Одностраничная демо-версия сайта (тот же дизайн, без сборки).
  baikal-eyes.html  Готовый файл — можно открыть двойным щелчком в браузере.
  src/p1…p6.html    Части, из которых он собирается:
                      p1, p2 — стили
                      p3     — шапка, подвал, логотип
                      p4     — контакты и движок графики
                      p5     — данные маршрутов и шаблоны страниц
                      p6     — навигация, формы, анимации
  build.sh          Пересобрать baikal-eyes.html из частей:  ./build.sh

logo/             Логотип в векторе (отрисован по присланному изображению):
  baikal-eyes-full.svg   знак + надпись
  baikal-eyes-mark.svg   только знак
  baikal-eyes-word.svg   только надпись
  logo-original.jpg      исходник, который вы прислали
```

## Структура сайта

- **Экскурсии** — выезды на день и короче (5 маршрутов).
- **Туры** — маршруты с ночёвками (6 маршрутов).
- **Что взять** — памятка по сборам: зима, лето, межсезонье, «мы возим сами», советы.
- Плюс: главная, «О нас», «Контакты», страница каждого маршрута.

## Шрифты

Manrope и Cormorant Garamond подключаются ссылкой на Google Fonts в `nextjs/src/app/layout.tsx`
и в прототипе — то есть загружаются в браузере посетителя. Проект собирается без интернета.

## Что стоит заменить

1. **Фотографии.** На первом экране стоит ваш снимок:
   `nextjs/public/images/hero.jpg` (горизонтальный, для компьютера) и
   `hero-portrait.jpg` (вертикальный, для телефона) — те же файлы лежат в `prototype/images/`.
   Чтобы поменять: положите новые файлы с теми же именами.
   Остальные визуалы пока рисуются кодом — как подставить свои снимки, см. `nextjs/README.md`.
2. **Тексты памятки** «Что взять с собой» — `nextjs/src/lib/packing.ts` (в прототипе — объект
   `PACKING` в `prototype/src/p5.html`).
3. **Тексты трёх новых туров** (Большое кольцо, КБЖД, Аршан) написаны по типовым маршрутам —
   проверьте цены и программу.

Контакты в проекте: `nextjs/src/lib/contacts.ts` и объект `CONTACTS` в `prototype/src/p4.html`.
